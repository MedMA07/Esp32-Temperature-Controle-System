# Esp32-Temperature-Controle-System
Système IoT de régulation thermique (ESP32/NTC 10k). Contrôle par hystérésis avec triple interface : écran OLED local, serveur Web WiFi et dashboard graphique temps réel en Python (Matplotlib). Gestion des paramètres sans reprogrammation. Projet complet combinant hardware, firmware et supervision logicielle.
